# Social Coach 🎯

> 写代码有 Git log，社交为什么没有？

数据驱动的社交成长教练，OpenClaw Agent Skill。

通过记录真实邀约、破冰、会话等数据，帮助用户发现行为模式、识别关键成功/失败因素，迭代社交策略。

**如果你是不善言辞的码农，或者是没有贡献过代码的情场高手——**
**欢迎贡献代码，重铸荣光。**

## 特性

- 📊 **数据驱动** — 每次交互自动记录，用数据发现模式
- 🔄 **持续迭代** — 基于历史数据生成个性化建议
- 🧠 **心态管理** — 被拒后自动情绪干预，防止消极螺旋
- 📈 **进步追踪** — 可视化社交能力成长曲线
- 🚫 **反 PUA** — 禁止操纵话术，鼓励真诚交往

## 指令

| 指令 | 用途 |
|------|------|
| `/记录邀约` | 记录一次真实邀约（最高优先级） |
| `/破冰` | 破冰训练（真实/模拟） |
| `/邀约话术` | 根据场景生成低压力话术 |
| `/深度会话` | 对话复盘 |
| `/模拟` | AI 扮演对方对话练习 |
| `/复盘 [代号]` | 复盘某次邀约 |
| `/心态` | 情绪管理 |
| `/统计` | 阶段性数据报告 |

## 安装

```bash
clawhub install social-coach
```

或手动将 `social-coach/` 目录放入 OpenClaw skills 目录。

## 数据存储

所有用户数据存储在 `~/.openclaw/workspace/memory/social-coach/` 下，完全本地，不上传任何外部服务。
