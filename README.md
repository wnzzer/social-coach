# Social Coach 🎯

> 写代码有 Git log，社交为什么没有？

一个教你**脱单**的 AI 教练。不是那种教你"三步拿下"的油腻教程——是认真帮你记每一笔"失败账"，然后告诉你：**你看，你其实在上次就差一点了。**

## 所以这东西到底干啥

你约人出去过吗？结果怎么样？还记得上次聊天聊到哪了吗？大概率不记得。

Social Coach 会帮你：
- 📊 记下每一次邀约的细节和结果，像 Git log 一样可追溯
- 🧠 当你连着被拒心态崩了，它比你的兄弟更早发现，并拉你一把
- 📈 过个两周回头看——卧槽，我居然进步了
- 🚫 **拒绝 PUA**，尊重是底线，技巧只是加成

## 适合谁

- ✅ 写代码 6 到飞起，跟异性说话舌头打结
- ✅ 每次被拒完想不通为什么，复盘全靠脑补
- ✅ 想认真提升社交能力，不是学套路
- ❌ 想学"话术操控术"的请出门右转

**无论你是不善言辞的码农，还是没写过代码的情场高手——重铸码农荣光，我辈义不容辞。**

## 指令

| 指令 | 用途 |
|------|------|
| `/记录邀约` | 记录一次真实邀约（最高优先级） |
| `/破冰` | 破冰训练（真实/模拟） |
| `/邀约话术` | 根据场景生成低压力话术 |
| `/深度会话` | 对话复盘 |
| `/模拟` | AI 扮演对方对话练习 |
| `/复盘 [代号]` | 复盘某次邀约 |
| `/心态` | 情绪管理 |
| `/统计` | 阶段性数据报告 |

## 安装

```bash
clawhub install social-coach
```

或手动将 `social-coach/` 目录放入 OpenClaw skills 目录。

## 数据存储

所有用户数据存储在 `~/.openclaw/workspace/memory/social-coach/` 下，完全本地，不上传任何外部服务。
